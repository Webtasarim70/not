Quartz'ta bundan sonra sık kullanılan özelleştirmeler:

- Site adı → `quartz.config.ts`
- Açıklama (SEO) → `quartz.config.ts`
- Sol menü bağlantıları → `quartz.layout.ts`
- Tema renkleri → `quartz/styles`
- Footer metni → `quartz/components/Footer.tsx`
- Özel alan adı (domain) → GitHub Pages ayarları + `CNAME`

gibi iyileştirmeleri de yapabiliriz.
